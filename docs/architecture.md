# Architecture and project boundaries

This repository is a portfolio index for independent Kaggle experiments. It is not a shared training package and the notebooks do not pass artifacts to one another unless a notebook explicitly documents that relationship.

## Portfolio map

### Synthetic insurance-review NLP

```text
Prompt schema + user-owned Gemini key
                 |
                 v
       Synthetic review records
                 |
                 v
   Data validation and text cleaning
                 |
        +--------+---------+
        |        |         |
        v        v         v
   Sentiment   Rating    Topics
   baseline   baseline    (LDA)
```

Security boundary: the API key is runtime-only. Data generated by a model must still be reviewed for privacy, bias, factuality, and provider-policy compliance.

### Financial-news sentiment baseline

```text
          v

          |
          v
```

The committed metric is evidence for one notebook run only. The output is not financial advice.


The committed notebook is an unexecuted snapshot. Hardware, model-weight, data-license, and privacy requirements must be resolved by the runner.

## What CI proves

The repository workflow parses all root notebooks as JSON, confirms a notebook/cell structure, records execution-state counts, and searches for a small set of high-confidence token formats. It deliberately does not:

- download datasets or model weights;
- call Gemini or any other external API;
- train models;
- assert that historical outputs reproduce on a newer runtime;
- perform a comprehensive security or licensing audit.
